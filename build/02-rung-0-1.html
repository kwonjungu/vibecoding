시작 전에 잡아 둘 네 가지

앱은 식당과 같습니다

홀

학생이 보고 만지는 화면입니다.

주방

선생님만 아는 저장과 계산입니다.

주문서

홀과 주방이 주고받는 정해진 양식입니다.

건물

설계 목적 설정

누가, 어디서, 무엇을, 몇 분 안에 하는지를 한 줄로 적습니다. 4학년 25명이 전자칠판 앞에서 지도 퀴즈를 10분 안에 푼다. 이 한 줄이 프롬프트의 뼈대입니다.

누가 · 어디서

사람 수와 장소가 정해지면 화면과 글자 크기가 정해집니다.

무엇을

기능은 하나로 좁힙니다. 둘이 되면 완성까지 네 배 멉니다.

몇 분 안에

시간을 적어 두면 여기서 멈춰도 된다는 선이 생깁니다.

도구 선택

Gemini 안에서 홀을 꾸밉니다. 앱 파일 한 개를 빠르게 뽑습니다.

AI Studio

API 키까지 주는 작업실입니다. 여러 파일로 된 앱을 다룹니다.

안 돼요 대신 어디까지 됐고 무엇이 나왔는지 말합니다. 세 번 막히면 백업 파일로 돌아갑니다.

오류 다루기

빨간 글씨는 한 글자도 바꾸지 말고 복사해 붙여넣습니다.

학생 정보

학생 이름과 얼굴은 올리지 않습니다. 학급 코드와 번호로 들어오게 합니다.

열쇠와 자료

API 키는 서버에만 둡니다. 교과서 자료가 든 앱은 교실 안에서만 씁니다.

시작하기 전 확인

  • 누가 어디서 무엇을 몇 분 안에 하는지 한 줄로 적었습니다.
  • 고치기 전에 백업 파일을 만들어 두었습니다.
  • 지금 한 번에 하나만 고치고 있습니다.
  • 화면과 파일에 학생 이름과 얼굴이 없습니다.
  • API 키가 코드 안에 적혀 있지 않습니다.
