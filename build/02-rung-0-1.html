STEP 00

준비물 챙기기

도구는 모두 무료이고 설치할 것도 없습니다. 다만 계정 세 개는 미리 만들어 둡니다. 연수장에서 가입 메일을 기다리면 첫 실습 칸을 놓칩니다.

계정 세 개를 미리 만듭니다

GitHub

앱을 인터넷 주소로 바꿔 주는 곳입니다. 4칸에서 폴더를 올리면 무료 호스팅(GitHub Pages)이 주소를 내어 줍니다. 그 주소를 QR로 만들어 학생에게 나눠 줍니다.

사용자명은 영문 소문자와 숫자, 하이픈만 됩니다. 이 이름이 앱 주소에 그대로 붙으니 짧게 짓습니다.

GitHub 가입 페이지 열기

Google AI Studio

말로 앱을 만드는 작업실입니다. 2칸부터 7칸까지 가장 오래 머뭅니다. 여러 파일로 된 앱을 만들고 그 자리에서 배포까지 합니다.

반드시 개인 Gmail로 로그인합니다. 학교 계정은 막히는 경우가 많습니다.

Google AI Studio 열기

Firebase

학생 30명이 동시에 같은 순위표를 보게 해 주는 서버입니다. 이 사다리에서 쓰는 유일한 서버로, 5칸과 6칸에서 붙여 7칸까지 이어 씁니다. 콘솔에서 스위치 하나만 켜면 나머지는 AI가 붙여 줍니다.

AI Studio와 같은 개인 Gmail을 쓰고, 카드 등록 없이 무료 요금제(Spark)로 씁니다.

Firebase 콘솔 열기

이러면 성공입니다

  • GitHub 화면 오른쪽 위에 내 사용자명이 보입니다.
  • AI Studio에 들어가면 로그인 창이 아니라 채팅 입력 칸이 나옵니다.
  • Firebase 콘솔에 프로젝트 목록 화면이 열리고 결제 안내가 뜨지 않습니다.

STEP 01

더 나은 바이브코딩을 위한 배경지식

실습이 없는 칸입니다. 시작하기 전에 판단할 네 가지를 정리합니다. 무엇을 만들지 정하는 법, 도구를 고르는 기준, 고칠 때의 순서, 지켜야 할 선입니다.

시작 전에 잡아 둘 네 가지

설계 목적 설정

무엇을 만들까 대신 무엇이 불편한가에서 출발합니다. 누가, 어디서, 무엇을, 몇 분 안에 하는지를 한 줄로 적습니다. 4학년 25명이 전자칠판 앞에서 지도 퀴즈를 10분 안에 푼다. 이 한 줄이 프롬프트의 뼈대이자 기준선입니다.

누가 · 어디서

사람 수와 장소가 정해지면 화면과 글자 크기가 따라 정해집니다.

무엇을

기능은 하나로 좁힙니다. 둘이 되면 완성까지의 거리가 네 배입니다.

몇 분 안에

시간을 적어 두면 여기서 멈춰도 된다는 선이 생깁니다.

도구 선택

이 페이지는 앱을 식당에 빗댑니다. 🟡 홀은 학생이 보고 만지는 화면이고 🟦 주방은 선생님만 아는 저장과 계산입니다. 이번 연수는 설치가 필요 없는 두 가지만 씁니다.

Canvas

Gemini 안에서 홀을 꾸밉니다. 앱 파일 한 개를 빠르게 뽑을 때 좋습니다.

AI Studio

주방 열쇠인 AI 사용 열쇠(API 키)까지 주는 작업실입니다. 여러 파일로 된 앱을 다룹니다.

설치형 도구

학교 컴퓨터에 설치 권한이 없어 이번에는 뺍니다.

고를 때는 설치 권한, 무료로 쓰는 조건, 한도가 잠기면 수업이 멈추는지를 봅니다.

과정

한 번에 완성되지 않습니다. 두 가지를 같이 고치면 어느 쪽이 망가뜨렸는지 알 수 없습니다.

크게 한 번

무엇을 만들지, 어떻게 보일지, 누구를 위한 것인지를 처음 프롬프트에 적습니다.

백업 먼저

고치기 전에 파일을 복사해 index_백업.html로 남깁니다.

하나씩만

색을 바꿨으면 화면을 확인하고 그다음 글자 크기를 바꿉니다.

마인드셋

오류는 실패가 아니라 정보입니다. 안 돼요 대신 어디까지 됐고 무엇을 눌렀을 때 무엇이 나왔는지 말합니다. 세 번 막히면 백업 파일로 돌아갑니다. 학생 이름과 얼굴은 공개 저장소에 올리지 않습니다.

오류 다루기

빨간 글씨는 한 글자도 바꾸지 말고 복사해 붙여넣습니다. 요약하면 AI도 짐작합니다.

학생 정보

학생은 회원가입 없이 학급 코드와 번호로 들어옵니다. 코드는 수업이 끝나면 바꿉니다.

열쇠와 자료

API 키는 서버에만 둡니다. 교과서 지문이나 삽화가 들어간 앱은 교실 안에서만 씁니다.

시작하기 전 확인

  • 만들기 전에 누가 어디서 무엇을 몇 분 안에 하는지 한 줄로 적었습니다.
  • 고치기 전에 백업 파일을 만들어 두었습니다.
  • 지금 한 번에 하나만 고치고 있습니다.
  • 화면과 파일 어디에도 학생 이름이나 얼굴이 들어가지 않았습니다.
  • API 키가 코드 안에 적혀 있지 않습니다.
