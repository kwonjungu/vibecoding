SAFETY

공개하기 전에

주소가 생겼다는 것은 누구나 열어 볼 수 있다는 뜻입니다.

확인할 네 가지

API 키

코드에 적지 않고 화면에 띄우지 않고 캡처로 공유하지 않습니다. 서버 쪽 비밀값으로만 둡니다. 새어 나갔다면 삭제하고 새로 만듭니다.

개인정보

학생 이름과 얼굴 사진은 공개 저장소에 올리지 않습니다. 회원가입 없이 학급 코드와 번호로 들어오게 하고 서버에는 번호와 별명, 점수만 남깁니다.

저작권

교과서 지문이나 삽화가 든 앱은 교실 안에서만 쓰고 공개하지 않습니다.

공개 범위

Public 저장소는 주소를 아는 누구나 들어옵니다. 학급 코드는 수업이 끝나면 바꿉니다.

공개 전 확인

  • 코드와 캡처 어디에도 API 키가 없습니다.
  • 학생 이름과 얼굴이 저장소에 없습니다.
  • 교과서 자료가 든 앱은 주소를 내지 않았습니다.
  • 학급 코드 바꾸는 곳을 확인했습니다.

LIMITS

무료로 어디까지 되나요

도구마다 하루에 쓸 수 있는 양이 정해져 있습니다. 2026년 9월 기준 값입니다.

도구 무료로 되는 범위 알아 둘 점
Gemini API 무료 등급은 Flash 계열만 됩니다. gemini-2.5-flash는 분당 10회에 하루 250회입니다. gemini-2.5-flash-lite는 분당 15회에 하루 1,000회입니다. 모델 이름을 어느 쪽으로 적었는지에 따라 한도가 네 배 차이 납니다.
Firebase Spark(무료) 결제 수단 없이 Firestore와 Hosting, Authentication을 씁니다. Firestore는 하루에 읽기 50,000회, 쓰기 20,000회, 삭제 20,000회까지 됩니다. 저장 공간은 1GB입니다. 5칸과 6칸이 이 범위 안에서 돕니다.
Firebase Cloud Storage 파일 업로드를 맡는 자리입니다. 2026년 2월 3일부터 버킷 생성에 결제 계정이 필요합니다. 이 페이지에서는 쓰지 않습니다. 6칸의 사진은 줄여서 Firestore에 문자열로 넣습니다.
GitHub Pages Public 저장소면 무료입니다. 4칸의 주소 만들기가 여기서 끝납니다.

한 학급 한 수업 분량은 가장 작은 칸에도 들어갑니다. 계산은 7칸 앱이 AI를 부르게에 있습니다.

BEYOND

더 멀리 가려면

설치 권한이 없거나 한도가 잠기면 수업이 멈추므로, 이 사다리는 브라우저에서만 되는 도구로 짰습니다.

설치형 통합 개발 도구로는 Claude Code, Codex CLI, Antigravity, Cursor, Windsurf, Cline이 있습니다. 폴더 만들기부터 주소 내기까지 한 문장으로 맡기지만 설치가 필요하고 무료 조건이 제각각이라 이름만 알려 드립니다.

도구가 바뀌어도 화면을 만들고, 저장할 곳을 정하고, 주소를 내는 순서는 같습니다.

설치형으로 넘어갈 때 확인할 세 가지

  • 학교나 집 컴퓨터에 설치할 수 있습니까.
  • 무료 조건이 무엇입니까. 플랜과 키, 한도를 봅니다.
  • 한도가 잠기면 수업이 멈춥니까.
