SAFETY

공개하기 전에

주소가 생겼다는 것은 누구나 열어 볼 수 있다는 뜻입니다.

확인할 네 가지

API 키

코드에 적지 않고 화면에 띄우지 않고 캡처로 공유하지 않습니다. 서버 쪽 비밀값으로만 둡니다. 새어 나갔다면 삭제하고 새로 만듭니다.

개인정보

학생 이름과 얼굴 사진은 공개 저장소에 올리지 않습니다. 회원가입 없이 학급 코드와 번호로 들어오게 하고 서버에는 번호와 별명, 점수만 남깁니다.

저작권

교과서 지문이나 삽화가 든 앱은 교실 안에서만 쓰고 공개하지 않습니다.

공개 범위

Public 저장소는 주소를 아는 누구나 들어옵니다. 학급 코드는 수업이 끝나면 바꿉니다.

공개 전 확인

  • 코드와 캡처 어디에도 API 키가 없습니다.
  • 학생 이름과 얼굴이 저장소에 없습니다.
  • 교과서 자료가 든 앱은 주소를 내지 않았습니다.
  • 학급 코드 바꾸는 곳을 확인했습니다.

LIMITS

무료로 어디까지 되나요

도구마다 하루에 쓸 수 있는 양이 정해져 있습니다. 2026년 9월 기준 값입니다.

도구 무료로 되는 범위 알아 둘 점
Gemini API 무료 등급은 Flash 계열만 됩니다. gemini-2.5-flash는 분당 10회에 하루 250회입니다. gemini-2.5-flash-lite는 분당 15회에 하루 1,000회입니다. 지금은 AI Studio Build가 앱 안에서 씁니다. 모델 이름을 어느 쪽으로 적었는지에 따라 한도가 네 배 차이 납니다.
Groq console.groq.com에서 무료 열쇠를 각자 발급받습니다. 모델은 llama-3.1-8b-instant가 초당 560자, llama-3.3-70b-versatile가 초당 280자입니다. 7칸의 캘린더 정리 어시스턴트가 씁니다. 열쇠는 gsk_로 시작합니다. 부르는 방식과 주소는 OpenAI와 같습니다.
Firebase Spark(무료) 결제 수단 없이 Firestore와 Hosting, Authentication을 씁니다. Firestore는 하루에 읽기 50,000회, 쓰기 20,000회, 삭제 20,000회까지 됩니다. 저장 공간은 1GB입니다. 5칸과 6칸이 이 범위 안에서 돕니다.
Firebase Cloud Storage 파일 업로드를 맡는 자리입니다. 2026년 2월 3일부터 버킷 생성에 결제 계정이 필요합니다. 이 페이지에서는 쓰지 않습니다. 6칸의 사진은 줄여서 Firestore에 문자열로 넣습니다.
Supabase 카드 등록 없이 무료입니다. 데이터베이스 500MB, 프로젝트 2개까지입니다. 6칸의 심화 미션이 씁니다. 이레 동안 아무도 쓰지 않으면 프로젝트가 잠깁니다. 방학이 지나고 열면 멈춰 있습니다.
GitHub Pages Public 저장소면 무료입니다. 4칸의 주소 만들기가 여기서 끝납니다.
AI Studio(Publish) Starter Tier로 결제 수단 없이 배포합니다. 무료 배포는 계정마다 두 번 더 주어지고, 넘으면 쓴 만큼 요금이 붙습니다. 4칸의 길 C입니다.
Vercel 무료로 깃허브 저장소를 연결해 배포하고 환경변수를 넣습니다. vercel.com/drop은 파일이나 폴더, zip을 끌어다 놓으면 Git도 CLI도 없이 배포됩니다(2026년 6월). 7칸의 서버 함수와 환경변수가 여기서 돕니다. 4칸의 길 D가 이 끌어다 놓기입니다.

한 학급 한 수업 분량은 가장 작은 칸에도 들어갑니다. 모델을 고르는 표는 7칸 나만의 캘린더에 AI 붙이기에 있습니다.
