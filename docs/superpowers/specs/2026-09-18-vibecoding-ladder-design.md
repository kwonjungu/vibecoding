# 바이브코딩 사다리 — 설계 문서

작성일 2026-09-18 · 저장소 `kwonjungu/vibecoding` · 배포 예정 `https://kwonjungu.github.io/vibecoding/`

## 1. 배경과 문제

평택교육지원청 초등 AI 디지털 전문가 아카데미 연수 「바이브코딩 심화편」(3·4교시, 15:00~16:50)을 구글 슬라이드 74장으로 설계해 두었다. 두 가지 문제가 확인되었다.

- **내용 수준**: 식당 비유 → AI Studio 이사 → assets → Apps Script + 시트 → 학급코드 연동 → GitHub Pages를 100분에 밀어 넣어, 비전공 교사 30명 기준으로 과하다.
- **전달 매체**: 74장을 순서대로 넘기는 방식이라 출발점이 다른 참가자가 중간에 이탈하면 복귀할 수 없다.

## 2. 해결 방향

한 줄로 늘어선 100분 대신 **8칸 사다리**로 재구성하고, 매체를 슬라이드에서 **정적 웹 페이지**로 옮긴다.

- 각 칸은 독립적으로 완결된다. 어느 칸에서 멈춰도 "여기까지만 해도 수업에 쓸 수 있다"가 성립한다.
- 참가자는 자기 위치를 스스로 확인하고 이탈 지점에서 복귀할 수 있다.
- 연수 100분에는 0~5칸을 함께 오르고, 6~7칸은 페이지에 남겨 사후에 잇는다.

형태는 기존 저장소 `kwonjungu/classroomaicontents`의 디자인 시스템과 마크업 패턴을 승계한다.

|---|---|---|---|
| 0 | 준비물 챙기기 | GitHub · Google AI Studio · Firebase | 계정 3개 |

### 칸별 내용

**0. 준비물 챙기기**
계정 3개를 각각 카드로 제시한다. 카드마다 로고 · 가입 버튼 · 주의사항 한 줄.
- GitHub — 사용자명은 영문 소문자·숫자·하이픈. 주소에 그대로 붙는다.
- Google AI Studio — 개인 Gmail로 로그인. 학교 계정은 막히는 경우가 많다.
- Firebase — 같은 개인 Gmail. 카드 등록 없이 Spark(무료) 그대로 쓴다.

**1. 더 나은 바이브코딩을 위한 배경지식** (개념 칸 — 실습 없음)
네 덩어리로 구성한다.
- *설계 목적 설정*: "무엇을 만들까"가 아니라 "무엇이 불편한가"에서 출발. 만들기 전 한 줄로 적는다 — 누가 · 어디서 · 무엇을 · 몇 분 안에. 예) "4학년 25명이 · 전자칠판 앞에서 · 지도 퀴즈를 · 10분 안에." 이 줄이 프롬프트의 뼈대이자 "이 정도면 됐다"의 기준선이 된다.
- *도구 선택*: Canvas는 홀만 꾸미는 인테리어 앱, AI Studio는 주방 열쇠(API 키)까지 주는 곳, 설치형 도구는 설계·시공·입주를 맡기는 공사업체. 고르는 기준 셋 — 학교 컴퓨터에 설치할 수 있나 · 무료 조건이 무엇인가 · 한도가 잠기면 수업이 멈추나.
- *과정*: 한 번에 완성이 아니라 대화. 크게 한 번 만들고 그 뒤엔 한 번에 하나씩만 고친다. 고치기 전 백업(`index_백업.html`)이 가장 값싼 안전장치. 프롬프트에 넣을 세 가지 — 무엇을 · 어떻게 · 누구를 위해.
- *마인드셋*: (디버깅) 오류는 실패가 아니라 정보다. 빨간 글씨를 그대로 복사해 AI에게 붙여넣는 것이 가장 빠르다. "안 돼요"가 아니라 "어디까지 됐고 무엇을 눌렀을 때 무엇이 나왔는지"를 말한다. 세 번 시도해도 안 되면 백업으로 돌아간다. (개인정보) 학생 이름·얼굴은 공개 저장소에 올리지 않는다. 학생은 회원가입 없이 학급 코드 + 번호로 들어온다. API 키는 코드에 넣지 않고 서버에만 둔다. 교과서 지문·삽화가 든 앱은 교실 안에서만 쓴다. 학급 코드는 수업이 끝나면 바꾼다.

**2. 말로 앱 만들기** — Gemini Canvas에서 프롬프트만으로 한 파일 앱(`index.html`)을 만들고, 메모장에 UTF-8로 저장해 더블클릭으로 연다. 저장 주의 3가지(인코딩 UTF-8 · 파일 형식 모든 파일 · 이름 `index.html`, `.txt` 아님).

**3. 재료 만들어 붙이기** — 앞머리에서 Canvas → AI Studio로 이사한다(여러 파일을 다루는 순간이므로 명분이 자연스럽다). 시스템 지시는 "항상 `index.html` 전체를 코드블록 하나로, 생략 없이". 그림은 Gemini 이미지 생성으로 만들어 `assets/`에 영문 소문자 파일명으로 넣고, AI에게는 그림이 아니라 **경로**를 알려 준다. 효과음은 외부 파일 없이 **코드가 직접 만들게** 한다(Web Audio) — 내려받기·파일명·경로 문제가 전부 사라진다. 재료 프롬프트 원칙 4가지: 스타일 접두어 고정 · 배경 단색 · 시리즈는 한 장에 2×2 · 정사각형.

**4. 주소 만들기** — 저장소 생성(Public, README 체크 안 함) → `index.html`과 `assets` 폴더째 업로드 → Settings › Pages › `main` / `(root)` → `https://[아이디].github.io/[저장소명]/`. 1~3분 대기, Actions 탭 초록 체크 확인. 플랜 B: Netlify Drop, AI Studio Build.

**5. 결과 모으기 (쉬운 길)** — 구글 시트 생성 → 확장 프로그램 › Apps Script → 코드 붙여넣기 → 웹 앱으로 배포(실행: 나 / 액세스: 모든 사용자) → `/exec` 주소에서 `{"ok":true}` 확인 → `index.html` 맨 위 `SERVER_URL`에 붙여넣고 학급 코드 입장 + 결과 저장 붙이기. 주문서 양식 `join` / `save`. Apps Script 특성상 반드시 POST · `Content-Type: text/plain;charset=utf-8` · `redirect: "follow"`. 교사 대시보드는 따로 만들지 않는다 — 시트가 이미 대시보드다.

**6. 진짜 데이터베이스** — Firebase 콘솔에서 프로젝트 생성 → Firestore 데이터베이스 만들기 → 웹 앱 등록으로 config 획득 → 정적 페이지에서 Firebase 웹 SDK를 CDN으로 불러 바로 저장/구독. 시트와의 차이는 **실시간**과 **동시 접속**. 보안 규칙을 반드시 복붙 블록으로 제공한다(기본 테스트 모드는 30일 뒤 잠기고 그 전까지는 전체 공개).

**7. 앱이 AI를 부르게** — AI Studio에서 Gemini API 키 발급 → Apps Script 스크립트 속성 `GEMINI_KEY`에만 저장 → `{action:"ai", question}` 주문서로 힌트 한 문장. 키는 공유·캡처·코드 삽입 모두 금지. 새어 나가면 삭제하고 재발급.

## 6. 디자인 시스템

`classroomaicontents/styles.css`를 승계한다.

- 색: 검정 `--ink #111` · 흰색 `--canvas` · 소프트클라우드 `#f5f5f5`가 화면의 95%
- 타이포: 캠페인 헤드라인 Black Han Sans / Bebas Neue (96px, line-height 0.9), UI는 Pretendard
- 버튼: 전부 pill(`--rounded-lg 30px`) 또는 원형 아이콘
- 카드: 그림자·라운드 없이 평평하게
- 간격: 8px 기준, 섹션 사이 48px
- 마크업 패턴: `.lecture` › `.lecture-row`(`.lecture-media` + `.lecture-copy`, `reverse` 교차) + 접기/펼치기 `.lecture-detail`, 내부는 `.note-cards`·`.guide-key`/`.key-grid`·`.guide-shot`

## 8. 이미지 정책

- 각 칸 상단에 **공식 브랜드 로고**를 넣는다. 대상: GitHub, Google AI Studio, Firebase, Gemini, Google Sheets/Apps Script, GitHub Pages, Netlify. 원본이 바뀌면 깨지므로 핫링크하지 않고 `assets/logo/`에 내려받아 보관한다.
- **화면 캡처**(AI Studio 첫 화면, Apps Script 배포 창, Firebase 콘솔, Pages 설정)는 로그인해야 나오는 화면이라 이 작업에서 생성할 수 없다. `<figure class="guide-shot">` 자리와 `alt`만 두고 연수 전에 직접 촬영해 채운다. 기존 저장소 `assets/guide/`와 같은 방식이다.

## 10. 확인된 사실 (2026-09 기준)

- Gemini API 무료 등급은 Flash 계열만. `gemini-2.5-flash` 10 RPM / 250 RPD, `gemini-2.5-flash-lite` 15 RPM / 1,000 RPD.
- Firebase Spark(무료)는 결제 수단 없이 Firestore·Hosting·Authentication 사용 가능. Firestore 하루 읽기 50,000 · 쓰기 20,000 · 삭제 20,000, 저장 1GB.
- Cloud Storage for Firebase는 2026-02-03부터 버킷 생성에 결제 계정이 필요하다. **사다리에서 제외한다.**
- Firebase Studio는 2026-06-22부터 신규 가입·워크스페이스 생성이 중단되었고 2027-03-22 지원 종료 예정이다. **연수에서 쓸 수 없다.** 파이어베이스는 콘솔(Firestore) 용도로만 쓴다.
- Apps Script `fetch`는 `text/plain` POST + `redirect: "follow"`여야 CORS 오류가 나지 않는다.

## 11. 범위 밖

- CLI·IDE 계열 도구(Claude Code·Codex CLI·Antigravity·Cursor·Windsurf·Cline 등) — "더 멀리 가려면" 한 문단으로만 언급, 실습 없음
- Firebase Studio, Firebase Cloud Storage — 위 사유로 제외
- 라이브 현황판(연수생 제출 → 강사 화면 집계) — 읽기 전용 정적 페이지 결정에 따라 제외
- 진도 체크·복사 버튼 등 상태를 저장하는 기능 — 같은 사유로 제외
- 손그림·활동지 사진으로 앱 만들기 — 재료를 전부 AI로 생성하므로 제외
- sfxr, Squoosh — 같은 사유로 제외. 효과음은 코드가 생성한다.
